v1.0.0-beta

Current Release
Released: 2026-11-19

✨ Major Capabilities

  • PoseGuardNet Model: Lightweight 214,597 parameter Conv1D-Residual-BiGRU network (855 KB checkpoint).
  • 5 Defect Detectors: Automated identification of foot sliding, ground penetration, unnatural pose transitions, contact inconsistency, and bone stretch anomalies.
  • Calibrated Hybrid Engine: Cross-validates neural temporal defect scores against deterministic geometric boundaries.
  • Interactive 3D Web Studio: Embedded Three.js skeletal viewer with defect timeline scrub bar and frame-accurate inspection.
  • Multi-Format Ingestion: Pure-Python forward kinematics BVH parser and standardized NumPy (.npz, .npy) loaders.
  • Headless REST API & CLI: Automated batch QA via poseguard analyze, batch, inspect, and FastAPI endpoints.
  • 100% Offline CPU Execution: Inferences run in under 0.65 ms on standard multi-core CPUs with zero CUDA requirements.

🔒 Security & Hardening

  • Bounded file uploads to 50 MB to prevent resource exhaustion attacks.
  • Sanitized uploaded filenames using os.path.basename to prevent directory traversal vectors.
  • Configured localhost-only default network bindings and restricted CORS origins.
