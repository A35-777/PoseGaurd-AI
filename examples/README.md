This folder provides runnable 3D animation samples and pre-computed expected JSON audit reports so you can immediately test PoseGuard AI without downloading external motion-capture datasets.

## How to Run These Examples

### 1. CLI Analysis
Analyze any sample file and print a formatted summary table in your terminal:
```bash
# Analyze clean walk
poseguard analyze examples/sample_walk_clean.bvh

# Analyze defective motion and export new JSON
poseguard analyze examples/sample_foot_sliding.npz --format json --out-file my_report.json
```

### 2. Interactive 3D Web Studio
Launch the local web studio to view the 3D skeleton and scrub through defects frame-by-frame:
```bash
poseguard serve --port 8000
```
Open `http://localhost:8000` in your browser and drag-and-drop `examples/sample_walk_clean.bvh` or `examples/sample_foot_sliding.npz` into the viewport.

### 3. Python SDK
```python
from poseguard import PoseGuard

detector = PoseGuard()

# Analyze defective sample
result = detector.analyze("examples/sample_foot_sliding.npz")

print(f"Overall Status: {result.quality_summary.overall_status}")
for defect in result.defects:
    print(f"- [{defect.severity.upper()}] {defect.type} on {defect.joint} (Frames {defect.start_frame}-{defect.end_frame})")
    print(f"  Fix: {defect.suggested_correction}")
```
